## 如何使用 prompt

1. 打开 prompt 文件,复制 **Prompt** 下方的代码块。
2. 粘贴给 Kling 4.0。带时间分段(0–4s、4–8s…)的 prompt 是一条多镜头片段;图生视频的条目还需要一张参考图。
3. 生成后,针对不满意的部分重抽或微调。

部分作者只公开了部分 prompt,或只在帖子里描述了效果;这类文件会注明。
